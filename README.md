# AWS Lightsail 云电脑部署 Skill（已有账号版）

一个让 AI 帮你在**自己的 AWS 账号**上自动完成 Lightsail Windows 云电脑部署的 Skill：做完 5 个新手任务领满 $200 抵扣金、买机器、配网络、交付 RDP 连接信息。

> 本仓库是 [YT-smart/AWS-free-account](https://github.com/YT-smart/AWS-free-account) 的安全化改版（MIT 衍生）：**移除了全部账号注册与身份信息生成流程**，只保留针对已注册账号的正当部署自动化。

## 与原版的区别

| | 原版 | 本版 |
| --- | --- | --- |
| 账号注册 | AI 云浏览器代注册 | ❌ 不做注册，用户自行完成 |
| 身份信息 | AI 随机生成姓名/地址 | ❌ 不生成任何身份信息 |
| 登录 | 用户提供邮箱密码给 AI | 用户本人登录，AI 不经手密码 |
| 验证码 / CAPTCHA / 绑卡 | AI 代做或换环境绕过 | 一律暂停，用户本人完成 |
| 部署自动化 | ✅ | ✅ 保留全部 |

## 流程

登录后的所有页面导航由 AI 负责（Console Home、Explore AWS、Billing → Credits、Lightsail 控制台等），用户只负责登录和输验证码。

| 模式 | 内容 |
| --- | --- |
| **A** | 领抵扣金（5 个新手任务，建完即删）+ 部署服务器 |
| **B** | 只领抵扣金，不买服务器 |
| **C** | 只部署服务器（跳过新手任务） |

部署内容包括：Lightsail Windows Server 实例、套餐降级处理、静态 IP、RDP 防火墙规则、关闭 IPv6、32GB 数据盘、获取连接凭证并输出连接教程。

## 使用

把仓库地址发给支持浏览器自动化的 AI（Claude Code 等）：

```
帮我安装：https://github.com/chaucerj/aws-lightsail-windows，安装完成后按照流程开始工作
```

前提：你已用真实信息注册好 AWS 账号。本 Skill 不含注册环节，也不提供注册指引。

## 安全边界（写死在 SKILL.md 里，优先级最高）

- 只操作用户已用真实身份注册好的账号，不生成姓名 / 地址 / 邮编等任何身份信息
- 登录由用户本人在浏览器完成，AI 不索要、不代管 AWS 密码
- 绑卡 / 身份验证 / CAPTCHA：暂停交由用户本人完成，不代做、不绕过、不换环境重试
- 全程不提交付款信息；页面要求升级付费计划立即停止

## 费用提醒

- 抵扣金：注册赠送 $100 + 新手任务最多 $100（以控制台显示为准），自开户起 12 个月过期
- 免费计划满 6 个月或额度用完自动结束，到期前备份重要文件
- 新手任务创建的临时资源会全部删除，零花费预算提醒保留
